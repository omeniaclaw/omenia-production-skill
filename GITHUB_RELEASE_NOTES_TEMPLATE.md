# Release vX.Y.Z

## What This Is

Thin Omenia Production Skill client for authenticated access to Omenia Production Graph.

## What Is Not Included

- Backend logic
- Private rendering/selection/certification algorithms
- API keys
- Telegram tokens
- Generated media

## Install

Configure `baseUrl` and store your Omenia API key in your client secret store.

## Security

Run before publishing:

```bash
npm run self-test
```
